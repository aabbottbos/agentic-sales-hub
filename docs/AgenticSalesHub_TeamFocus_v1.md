# Team Focus

Agentic Sales Hub (ASH) is not just about single sales users. The core concepts and values apply to sales teams and broader organizations as well. This is for several reasons. From a sales perspective:
- accelerates onboarding: new members get the value of the skills tied to the company's context to be able to contribute faster
- deal support: teammates and managers can support sales cycles easier by leveraging the captured context 
- trend analysis: sales leaders can identify trends - common objections, new features or products requested, etc - faster to course correct or explore improvements.

It also has benefits for other parts of the organization.

Customer Success / Delivery: deal support and handoff becomes faster as all context is available.

Product: valuable signals about what's interesting prospects, etc

## What This Means

ASH needs to be constructed to support this. It should support direct interactions via harnesses like Claude / Claude Cowork as well as operate as agents in the background (imagine a skill/feature that automatically executes after every discovery call transcript is saved and provides sales coaching and feedback).
